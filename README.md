# 🛒 Carnes Guerra | Catálogo Online & Pedidos por WhatsApp

Sistema web interactivo y autogestionable para carnicerías y comercios de barrio, diseñado para **Carnes Guerra** (San Juan, Argentina). Permite a los clientes navegar por categorías, buscar productos, estimar pesos y enviar pedidos organizados directamente a WhatsApp sin pasar por pasarelas de pago complejas.

---

## 🚀 Características Principales

* **Sincronización con Google Sheets:** Los precios y productos se actualizan en tiempo real desde una hoja de cálculo en la nube mediante exportación CSV.
* **Cálculo de Peso Estimado:** Diseñado específicamente para carnicerías. Permite al cliente seleccionar cortes por kilo, gramos, piezas enteras o unidades/bifes, calculando un subtotal estimado transparente.
* **Garantía de Balanza:** Incluye avisos claros para transmitir tranquilidad al cliente (el ticket definitivo se define en mostrador y nunca supera lo estimado).
* **Selector de Modalidad:** Permite elegir entre **Retiro en Local** o **Envío a Domicilio (Delivery)**.
* **Métodos de Pago Interactivos:** Tarjetas visuales para Billetera Virtual (Mercado Pago), Tarjeta de Crédito/Débito y Efectivo.
* **Diseño Responsive & Mobile First:** Desarrollado con **Tailwind CSS**, optimizado al 100% para celulares con navegación fluida y barra de categorías táctil con desplazamiento horizontal.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5 / CSS3** (Estructura y diseño base)
* **Tailwind CSS (CDN)** (Estilos y diseño responsivo)
* **Font Awesome 6** (Iconografía)
* **JavaScript Vanilla (ES6+)** (Lógica del carrito, filtros, buscador y armado de pedidos para WhatsApp)
* **Google Sheets API / CSV Export** (Base de datos en la nube autogestionable)
